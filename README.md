# RecipeBox App Demo

Une application moderne de gestion de recettes construite avec Next.js, React, TypeScript et Tailwind CSS.

## Objectifs

- Gérer des recettes de manière simple et rapide
- Ajouter des recettes avec des informations utiles
- Créer une interface moderne et responsive
- Intégrer des services tiers comme Supabase et Stripe

## Stack technique

- Frontend : Next.js, React, TypeScript
- Styling : Tailwind CSS
- UI : shadcn
- Backend / base de données : Supabase
- Paiements : Stripe
- Analyse : Vercel Analytics
- Gestionnaire de paquets : pnpm

## Démarrage rapide

### Prérequis

- Node.js
- pnpm

### Installation

```bash
pnpm install
